## Sobre este repositório

Este é um repositório de **armazenamento de projetos e exercícios de estudo em Python**. Ele reúne anotações, experimentos e pequenos programas criados para transformar conceitos importantes em prática real.

O objetivo é construir uma base sólida para a carreira: dominar a lógica, escrever código legível, resolver problemas e avançar gradualmente para projetos mais completos.

> **Código estudado hoje é repertório profissional amanhã.**

## Trilhas de aprendizado

| Trilha                | Conceitos explorados                                  | Resultado esperado     |
| :-------------------- | :---------------------------------------------------- | :--------------------- |
| **Fundamentos**       | Variáveis, tipos, operadores e entrada de dados       | Lógica de programação  |
| **Controle de fluxo** | Condicionais, `for`, `while` e validações             | Programas com decisões |
| **Coleções**          | Listas, tuplas, dicionários, conjuntos e compreensões | Dados bem organizados  |
| **Funções e módulos** | Parâmetros, retorno, escopo e reutilização            | Código mais limpo      |
| **POO**               | Classes, métodos, composição e herança                | Sistemas estruturados  |
| **Qualidade**         | Exceções, testes, type hints e PEP 8                  | Código confiável       |
| **Próximos passos**   | APIs, arquivos, SQL, automação e web                  | Projetos do mundo real |

## Estrutura atual

```text
estudo-py/
├── concepts/
│   ├── condicionais.py/  # Decisões e comparações
│   ├── for.py            # Laços de repetição
│   ├── while.py          # Repetição com condição
│   └── coleções/
│       └── listas.py     # Primeiros estudos sobre listas
├── tests/                # Testes que serão adicionados ao longo da jornada
└── README.MD             # Visão geral do laboratório
```

## Como executar

```bash
git clone https://github.com/SEU-USUARIO/estudo-py.git
cd estudo-py
python concepts/coleções/listas.py
```

Para isolar as dependências de futuros projetos:

```bash
python -m venv .venv
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```
